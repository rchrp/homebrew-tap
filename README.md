# rchrp/homebrew-tap

Homebrew casks for [Blame](https://github.com/rchrp/Blame), the open-source ADE for AI coding agents.

```bash
brew install --cask rchrp/tap/blame
```

Blame updates itself. `brew upgrade --cask --greedy blame` also works.

The cask is updated automatically by Blame's [Release packages](https://github.com/rchrp/Blame/blob/main/.github/workflows/release-packages.yml) workflow when a stable version is published. Report problems on the [Blame issue tracker](https://github.com/rchrp/Blame/issues).
